## 1. 結論（先に）

**拡張パイプライン（知識ドラフト→監査→確定→構成→本文）は、以前の「いきなり回本文」より改善している。**  
特に誤解の予防、回どうしの物語線、技術・解釈の切り分けが明確になった。

一方で **ステップ4の講義構成**が各回10セクションに寄り、**30分×6000字**の本文が約8割前後で短め（length_pass はほぼ未達）。  
これは知識ドラフトの見出し数の問題ではない。次の改善ポイントは **構成（4）のセクション個数と target_chars 配分**。

総合: **方向性は採用してよい。構成フェーズの字数・セクション数チューニングが次タスク。**

### 用語の切り分け（確定）

## 3. 質的比較（第1回を中心に）

### 3.1 以前 Sonnet

- 歴史導入（黒体放射・光電効果・原子模型）が強い。
- 物語として読みやすいが、**現代入門で避けたい誤解の明示的ガードは弱い**。
- 6セクションでコンパクト。字数目標（当時）には合っていた。

### 3.2 以前 Luna / Terra（監査なし）

- 安い・速い。
- 字数が短く、概念の踏み込みが浅い回がある。
- プロンプト品質は後の画像比較で Terra 優位だったが、**知識の裏取り工程は無い**。

### 3.3 Foundation 後（今回）

**改善点**

1. **監査の効き**: 確定ドラフトに「観測＝意識ではない」「もつれ≠超光速」「デコヒーレンスと解釈の切り分け」などが明示。本文でも同趣旨が繰り返される。
2. **カリキュラムの一貫性**: 第1回量子化 → 第2回状態/確率 → 第3回干渉/測定 → 第4回もつれ/デコヒーレンス → 第5回技術と総合、という線がはっきりしている（旧 Sonnet 第1回は史話中心で、後続との接続は別設計）。
3. **導入の誠実さ**: 「量子＝とびとび」の単純化しすぎを補正する記述（連続も現れうる、など）が locked / 第1回に入っている。
4. **画像プロンプト**: 日本語ラベル付き・16:9・教材トーンで、現行 Image2 Low 方針と整合。

**弱点・退行**

1. **字数不足**: 6000字目標に対し ~4800–5400。厳格ゲートなら再生成ループが必要。
2. **講義セクション過多（構成フェーズ）**: 各回10は粒度が細かすぎ、1セクションあたりが薄くなりやすい。平均400字×10＝4000が心理的アンカーになり、6000に届きにくい。知識ドラフトの見出し数とは無関係。
3. **コスト**: 監査込みで本文だけで ~$0.75。旧 Luna 単体より高いが、品質・信頼性の対価として妥当な範囲。Sonnet 5回分よりは高いが、工程が違う。
4. **第4回 Terra フォールバック**: Luna が一度落ちた痕跡。品質は良いが単価が跳ねる。

## 4. 評価可否について

幕僚による評価は **可能**であり、本メモがその一次評価である。  
ただし次は限界がある:

- 物理の厳密なファクト監査は、監査ステップの Tavily 結果に依存（人間の専門家レビューの代替ではない）。
- 「受講者にとって面白いか」はサンプル1本では断定しきれない。

推奨: 殿下が第1回・第3回（干渉）・第4回（もつれ）をざっと読まれ、誤解表現の残りがないかだけ確認いただけると十分。

## 5. Next Step（提案）

1. **構成プロンプト修正（済み）**: 講義セクションは `round(目標字数/400)` 目安、上限10への張り付き禁止、総字数は target_chars で満たす。ドラフト見出し≠セクションを明示。
2. 必要なら **ステップ4・5を再実行**（構成のやり直し＋本文）。既存の locked は流用可。
3. 本文 length 未達時の短い追記パス（任意）。
4. 問題なければ画像 Low を第1回だけ見積もり→許可後。
5. モデル既定のコードロックは、構成の字数安定後。
