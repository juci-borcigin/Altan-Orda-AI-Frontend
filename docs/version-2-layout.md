**更新**: 2026-06-08

## 現状（V1 PC）

```
ヘッダー
└ 1200px 固定コンテナ
   └ flex row (gap 12px)
      ├ 左: ユーザー + ペルソナ（内容幅）
      ├ 中: flex 3 — メイン（論タブ + インプット + ビュー）
      └ 右: flex 2 — 空白スペーサー
```

メイン内: `論タブ | タイトル + 設定アイコン | 吹き出し + 邦主列（送信・添付・令旨）`

---

## 目標（V2 PC）

```
ヘッダー
└ 可変幅コンテナ（左 + gap + メイン）
   └ flex row (gap 12px)
      ├ 左カラム（250px）
      │   ├ ユーザーエリア（邦主・ルビ付きキャプション）
      │   ├ 設定エリア（年代記・使用量・設定 — 3 アイコン横並び）
      │   ├ プロジェクトエリア（論タブ縦列）
      │   └ ペルソナエリア（僚友）
      └ メインカラム（750px）
          ├ インプットエリア（タイトル + 吹き出し + 邦主顔グラ列）
          └ ビューエリア（チャット履歴 — 変更なし）
```

### 幅（100% 表示時）

| 項目 | px |
|------|-----|
| 全幅 | **1000** |
| 左カラム | **250**（比率 1） |
| メインカラム | **750**（比率 3） |

左:メイン = **1:3**。列間 gap は 0（250 + 750 = 1000）。微調整は `web/src/lib/ao-v2-layout.ts` の定数を変更する。

### 意図的な二重表示

- 左カラムのユーザー: 将来拡張可能なプロフィール領域
- インプット横の邦主顔グラ: 話者の演出的表示のみ

### スマホ（`viewportCompact`）

- **フェーズ 1a**: 変更なし（V1 レイアウト維持）
- **将来**: ドロワーにユーザー / 設定 / プロジェクト / ペルソナの 4 エリアを縦積み（案1）
