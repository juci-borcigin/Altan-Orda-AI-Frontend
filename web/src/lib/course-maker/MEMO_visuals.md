# 講義メーカー 備忘録（ビジュアル）

紙芝居: 1セクション＝1ページ＝セクション画1枚。

## セクション画に含めてよいもの

- 概念図・関係図・比較・流れなど。
- 説明に必要なら、人物像や数式風の記号が図の一部になることは妨げない（ハード禁止ではない）。

## 将来の別系統（専用ロジック候補）

### 人物の顔写真・専用人物グラフィック

- 本文へのインライン挿入や肖像スロットなど。
- 例: 発見者の写真、講師アバター。`visual_type = portrait` 等。

### 数式（本文レンダリング）

- 読める・編集できる本文数式（KaTeX 等）。
- セクション画内の装飾的な式とは役割が違う。
